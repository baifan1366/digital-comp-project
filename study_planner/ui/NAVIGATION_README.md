# 导航功能使用指南

## 概述

Study Planner 现在包含三个主要页面，通过顶部导航栏可以轻松切换：

- **🏠 Home**: 学习计划主页
- **📊 Analysis**: 学习分析页面
- **📜 History**: 历史记录页面

## 页面详情

### 1. Home 页面

这是应用程序的主页面，包含所有学习计划功能：

#### 快速开始
- 三个预设计划：Pomodoro、Deep Focus、Light Review
- 点击任意预设计划卡片即可选择

#### 自定义计划
- 计划名称：为你的计划命名
- 学习时间：设置学习时长（1-180分钟）
- 休息时间：设置休息时长（1-180分钟）
- 循环次数：设置重复次数（≥1）
- 长休息：可选的长休息时间（0-180分钟）

#### 最近使用
- 显示最近使用的5个计划配置
- 点击"加载选中的配置"快速重用

#### 学习统计
- 今日学习时间
- 本周学习时间
- 完成次数
- 中断次数

### 2. Analysis 页面

查看详细的学习分析和统计数据：

#### 本周学习统计
- **总学习时间**: 本周累计学习的总时长
- **学习次数**: 本周开始的学习会话总数
- **完成次数**: 本周成功完成的番茄钟数量
- **中断次数**: 本周中断或停止的会话数量

#### 计划使用统计
- **最常用的计划**: 显示你最常使用的学习计划及其使用次数
- **总学习时间**: 所有历史记录的累计学习时间

### 3. History 页面

以表格形式查看所有运行过的计划：

#### 表格列说明
- **计划名称**: 计划的名称（包括预设和自定义）
- **学习时间**: 每次学习的时长
- **休息时间**: 每次休息的时长
- **循环次数**: 计划设置的循环次数
- **使用时间**: 最后一次使用该配置的时间

#### Run Again 功能
1. 在表格中选择任意一条历史记录
2. 点击底部的 "▶️ Run Again" 按钮
3. 应用会自动：
   - 切换到 Home 页面
   - 加载选中的计划配置
   - 开始执行该计划

这个功能让你可以快速重复之前使用过的任何计划配置。

## 使用技巧

### 快速导航
- 使用顶部的导航按钮在页面间切换
- 当前页面的按钮会显示为深蓝色

### 数据刷新
- 每次切换到 Analysis 或 History 页面时，数据会自动刷新
- 确保你看到的始终是最新的统计信息

### 重复使用计划
有两种方式可以重复使用之前的计划：
1. **Home 页面的"最近使用"**: 显示最近5个配置，适合快速访问
2. **History 页面的 Run Again**: 可以访问所有历史记录，适合找回更早的配置

### 查看学习进度
- 定期查看 Analysis 页面了解学习习惯
- 关注"最常用的计划"来优化学习策略
- 监控中断次数，提高学习专注度

## 数据持久化

所有数据都会自动保存到本地：
- 历史记录：保存最近使用的计划配置
- 统计数据：记录每次学习会话的详细信息
- 位置：`%LOCALAPPDATA%\StudyPlannerApp\StudyPlanner\data.json`

## 键盘快捷键

目前支持的操作：
- 鼠标点击导航按钮切换页面
- 在 History 页面使用鼠标选择记录

## 故障排除

### 数据不显示
- 确保至少运行过一次学习计划
- 检查数据文件是否存在
- 尝试重启应用程序

### Run Again 不工作
- 确保在 History 页面选中了一条记录
- 检查是否有活动的学习会话（需要先停止）

### 统计数据不准确
- 统计数据基于完成的会话
- 中断的会话不计入学习时间
- 数据按周一到周日计算
